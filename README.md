# ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/your-portfolio.git
```

Move into the project folder:

```bash
cd your-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
